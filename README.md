# Port Said Hub — الباك إند الجديد (Next.js + Supabase)

ده أول جزء من الباك إند الجديد: **موديول تسجيل الدخول/التسجيل (Auth)** بديل
`app/Auth.php` القديم، شغّال على Next.js (API routes) وهيتنشر على فيرسل.
باقي الموديولات (Catalog, Rewards, Admin, Partners, Shop...) هتتبني بنفس
الطريقة في الخطوات الجاية.

## 1) التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # واملى القيم (Supabase URL + service_role key + JWT secret)
npm run dev
```

هيشتغل على `http://localhost:3000`. الـ endpoints:

| Method | Path                | يعمل إيه                              |
|--------|---------------------|----------------------------------------|
| POST   | `/api/auth/register`| تسجيل حساب جديد                        |
| POST   | `/api/auth/login`   | تسجيل دخول (`identifier` = إيميل أو هاتف) |
| POST   | `/api/auth/logout`  | تسجيل خروج                             |
| GET    | `/api/auth/me`      | بيانات المستخدم الحالي (محتاج تكون داخل) |

كل الردود JSON، والجلسة بتتخزن في كوكي httpOnly اسمها `ps_session` (JWT، مش
session بتاعة PHP، لأن فيرسل serverless ماعندوش ذاكرة مشتركة بين الطلبات).

## 2) النشر على فيرسل

- اربط الريبو بفيرسل، وضيف نفس متغيرات `.env.example` في Project Settings → Environment Variables.
- أهم حاجة: **`SUPABASE_SERVICE_ROLE_KEY` سري** — متحطّهوش في أي كود بيتبعت للمتصفح.

## 3) إزاي الفرونت القديم (لسه على InfinityFree) يكلم الباك إند الجديد مؤقتًا؟

الفرونت الحالي (`index.html`) فيه دالة واحدة بتبعت كل طلبات الـ API:

```js
return fetch('api/index.php?r=' + route + (qs || ''), o).then(readJson);
```

عشان يكلم الباك إند الجديد *قبل* ما ننقل الفرونت بالكامل لـ React، غيّر الدالة
دي بس (سطر واحد) لحاجة زي:

```js
const NEW_API = 'https://your-project.vercel.app'; // دومين فيرسل بتاعك
return fetch(NEW_API + '/api/' + route, { ...o, credentials: 'include' }).then(readJson);
```

وفي فيرسل حط:
```
ALLOWED_ORIGIN=https://your-old-site.infinityfreeapp.com
COOKIE_SAMESITE=none
```

(الاتنين موجودين في `.env.example` مع شرح أوسع). من غيرهم الكوكي مش هيتبعت
والـ CORS هيترفض الطلب لأن الدومينين مختلفين.

⚠️ **ده حل مؤقت لحد ما ننقل كل الـ endpoints**: دلوقتي بس `auth/*` شغالة هنا؛
أي route تاني (`meta`, `places`, `gallery`...) هيفضل لازم يروح للباك إند PHP
القديم. يعني في الفترة الانتقالية ممكن تحتاج شرط بسيط في الدالة ده: لو
`route` بيبدأ بـ `auth/` روح للجديد، غير كده سيبه للقديم. قولّي لو عايزني
أظبط الدالة دي بنفسي في نسخة `index.html` محدّثة.

- أي حاجة تانية غير auth (الأماكن، النقاط، الكوبونات، التجار، الإشعارات...).
